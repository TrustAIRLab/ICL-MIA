# Membership Inference Attacks Against In-Context Learning
The repository contains the code for the paper "Membership Inference Attacks Against In-Context Learning," where we investigate the vulnerability of in-context learning. The code is designed for the GPT2-XL model, but it can be easily adapted to other models.

For questions or issues, feel free to open an issue or contact us at [rui.wen@cispa.de](mailto:rui.wen@cispa.de).
